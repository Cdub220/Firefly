# Checkpoint reports

One record per scored moment, plus the standing pitch material. `cpN.md` is written by `/checkpoint N` and is the formal record: what exists, the number, the script, submission notes, definition of done, self-score. `cpN-talking-points.md` is the spoken layer: the script as it should be delivered with the current build, and the answers to the questions a judge will ask.

| File | What it is |
|---|---|
| `thesis.md` | The pitch in full: claim, where the information comes from, why it goes bad, what Kalman does, what ours does, the drones, generality, limits. Read this before any video. |
| `cp1.md` | Checkpoint 1 formal record (Sun 12:00 AM ET). |
| `cp1-talking-points.md` | Checkpoint 1 script using the split view, and judge Q&A. |
| `cp2.md` … `cp5.md` | Written by `/checkpoint N` at each deadline. |

Schedule and definitions of done: `docs/04b-checkpoint-deliverables.md`. Rubric: `docs/03-team-playbook.md` section 5.
