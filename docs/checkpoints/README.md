# Checkpoint reports

One record per scored moment. `cpN.md` is written by `/checkpoint N` and is the formal record: what exists, the number, the script, submission notes, definition of done, self-score. `cpN-talking-points.md` is the spoken layer: the script as it should be delivered with the current build, and the answers to the questions a judge will ask.

| File | What it is |
|---|---|
| `cp1.md` | Checkpoint 1 formal record (Sun 12:00 AM ET). |
| `cp2.md`, `cp2-report.md` | Checkpoint 2 formal record and the submitted report (estimator vs baseline, first evidence). |
| `cp3-report.md` | Checkpoint 3 submitted report: the freeze, the fair baselines, the Showdown case, how to reproduce. |
| `estimator-math.tex` / `.pdf` / `.html` | The estimator's math as frozen, with a what-changed page first. |

Schedule and definitions of done: `docs/04b-checkpoint-deliverables.md`. Rubric: `docs/03-team-playbook.md` section 5.
