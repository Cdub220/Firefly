# Pitch deck

`Firefly-Pitch.pptx` is generated by `make_deck.py` (python-pptx). Twelve slides; the spoken script is in each slide's speaker notes. To edit in Google Slides: drag the .pptx into Google Drive and open it, it converts with notes intact. To change the deck itself, edit `make_deck.py` and run:

```bash
pip3 install python-pptx
python3 docs/pitch/make_deck.py docs/pitch/Firefly-Pitch.pptx
```

Slide order: intro · the problem · what we're making · the market. Four slides, two speakers; the alternating script is in the notes.
